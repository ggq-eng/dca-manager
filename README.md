# dca-manager

> 来源分类：**原创/AI打磨** ｜ 导出批次：published

复利定投管理系统（DCA Manager）——包含可部署的单文件定投管理网页应用、A股实时行情代理、每日定投监控日报生成器与策略回归测试。当用户需要创建/部署复利定投管理程序、为某只股票生成每日定投监控日报（档位判定、止损/止盈点位、风险提示）、配置区间定投策略（上限暂停/区间正常/下限加码）、或对定投策略引擎做回归验证时使用。触发词：复利定投、定投管理、定投日报、每日定投监控、DCA、定投策略回测。

## 安装

把本文件夹整体复制到 WorkBuddy 技能目录：

```bash
cp -r . ~/.workbuddy/skills/dca-manager        # 用户级
# 或
cp -r . <项目>/.workbuddy/skills/dca-manager   # 项目级
```

重启/刷新 WorkBuddy 后即可在对话中触发。
